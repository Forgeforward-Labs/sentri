# Contract Test Plan

Use this workspace for the Hardhat test suite described in the SRD:

- `PolicyVault`: deposits, withdrawals, utilization math, premium accrual, locked liquidity checks.
- `InsuranceCore`: product creation, pending activation, claim initiation rules, single-payout enforcement.
- `AgentOrchestrator`: sequential three-agent flow, denial cases, request routing.
- `ClaimProcessor`: processed claim guard, payout execution ordering, reentrancy safety.
